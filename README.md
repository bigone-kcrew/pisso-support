# 피소 임직원 지원제도 지형도

공공기관이 **직무수행 중 고소·피소된 임직원에게 변호사비와 소송비용을 지원하는 제도**를 조사한 자료입니다. 대한법률구조공단의 대국민 "법률구조"와 이름만 같은, 기관 내부 제도가 대상입니다.

## 한눈에

| | |
|---|---|
| 제도를 둔 기관 | **95개** (독립 내규 53 · 법무규정 내 조항 42) |
| 재원을 자체수익·기금으로 명시한 조문 | **0건** — 확인된 재원은 전부 기관 일반예산 |
| 중소벤처기업부 소관 도입률 | **36.4%** (11개 중 4개) |
| 단체협약 조항을 둔 기관 | **12개** |

## 주요 발견

**1. 재원은 기관경비입니다.** 임직원 소송지원 맥락에서 "자체수익·수익금·기금"을 재원으로 지정한 조문은 한 건도 없었습니다. 재원을 규정한 기관은 예외 없이 기관 일반예산에서 집행하고, 회계상 영업외비용·잡손실로 처리합니다.

**2. 일부는 이미 법정 의무입니다.** 악성민원 피해 직원의 고소·고발 지원은 「산업안전보건법」 시행령 제41조제4호상 사업주 의무이며, 미이행 시 1천만원 이하 과태료 대상입니다.

**3. 단협이 내규를 끌어올린 경로가 있습니다.** 신용보증재단중앙회는 단협(2025)이 내규(2009)보다 16년 앞서 있고, 한국벤처투자는 2026년 단협에 "도입한다"를 신설했으나 아직 내규가 없습니다. 이 경우 "새 제도를 만들어 달라"가 아니라 **"이미 합의한 단협을 이행하라"**가 됩니다.

**4. 기관 예산으로 개인을 돕는 것은 위법하지 않습니다.** 조건은 셋 — 이사회 의결 규정, 예산과목 명시, 위원회를 통한 개별 승인.
