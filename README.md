# 피소 임직원 지원제도 지형도

공공기관이 **직무수행 중 고소·피소된 임직원에게 변호사비와 소송비용을 지원하는 제도**를 조사한 자료입니다. 대한법률구조공단의 대국민 "법률구조"와 이름만 같은, 기관 내부 제도가 대상입니다.

| 단체협약 조항을 둔 기관 | **12개** |

## 주요 발견

**1. 재원은 기관경비입니다.** 임직원 소송지원 맥락에서 "자체수익·수익금·기금"을 재원으로 지정한 조문은 한 건도 없었습니다. 재원을 규정한 기관은 예외 없이 기관 일반예산에서 집행하고, 회계상 영업외비용·잡손실로 처리합니다. 적립형 기금이 아니라 **사고 발생 시에만 지출되는 구조**입니다.

**2. 일부만 법정 의무입니다.** 악성민원 피해 직원이 **고소·고발할 때**의 지원은 「산업안전보건법」 제41조제2항·시행령 제41조제4호상 사업주 의무이며 미이행 시 1천만원 이하 과태료 대상입니다. 다만 이 조문은 고객응대근로자의 **건강장해 예방**을 위한 것이므로, 직원이 **피고·피의자가 되어 자신을 방어하는 비용**은 여기 포함되지 않습니다. 방어비용의 근거는 민법 제688조제3항의 취지, 구상권 제한 법리, 국가배상법 제2조제2항의 경과실 면책 취지로 따로 세워야 합니다.

**3. 단협이 내규를 끌어올린 경로가 있습니다.** 신용보증재단중앙회는 단협(2025)이 내규(2009)보다 16년 앞서 있고, 한국벤처투자는 2026년 단협에 "도입한다"를 신설했으나 아직 내규가 없습니다. 이 경우 "새 제도를 만들어 달라"가 아니라 **"이미 합의한 단협을 이행하라"**가 됩니다.

**4. 기관 예산으로 개인을 돕는 것은 위법하지 않습니다.** 조건은 셋 — 이사회 의결 규정, 예산과목 명시, 위원회를 통한 개별 승인.

## 06 창진원 규정안에 대하여

창업진흥원은 **단협 제33조에 "법률구조제도를 도입하기 위해 적극적으로 노력한다"가 있으나, 내규 「법무 및 소송사무 처리 규정」 제36조는 ①적극행정 인정 사건의 ②형사 피소에 한해 ③자문만** 제공합니다. 비용지원 근거가 없습니다.

제정안은 조사된 선례 중 **각 항목의 최고 수준**을 기준선으로 삼았습니다. 최고치는 대부분 **예금보험공사** 세칙에서 나옵니다.

| 항목 | 이 안 | 출처 |
|---|---|---|
| 변호사비 + 부대비용 | 심급당 **5천만원** | 예보 제5조①·제8조① |
| 수사·기소 전 단계 | **심급 1개로 계산** | 예보 제8조① |
| 외부기관 조사 | 건당 **2천만원** | 예보 제9조의4① |
| 손해배상금·합의금 | **상한 없음**(위원회 결정) | 예보 제6조④ |
| 총액 상한 | **없음** | 예보에는 총액 조항 자체가 없음 |
| 변호인 조사 동행 | 기관 변호사 지원 | 한국콘텐츠진흥원 제18조② |
| 대상 | 퇴직자·기간제·파견자 포함 | 예보 제2조3호 |

**수사기관 조사 단계**를 명시적으로 다룹니다. 피의자 신문 시 변호인 참여는 형사소송법 제243조의2상 권리이지만 **비용은 개인 부담**이고, 참고인 조사에는 **명문 규정 자체가 없습니다**. 규정이 메워야 할 곳이 바로 여기입니다.

각 조문에 출처 기관을 병기했고, **인용한 조문의 원문 32건을 접이식으로 실었습니다**(예금보험공사 세칙 9개조, 중진공 지침 5개조, 콘텐츠진흥원·코레일유통·창진원 등).

**법률자문이 아닙니다.** 실제 제정 시에는 기관 법무부서 또는 외부 변호사의 검토를 거치시기 바랍니다.
